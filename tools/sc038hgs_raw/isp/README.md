# SC038HGS 单色出图配置

此目录保留旧 OFFLINE ISP 出图实验的配置。当前 `dart_app` 已改为 ONLY_MCM
RAW10 → 二值图，不注册或加载这个场景，部署脚本也不再上传这些文件。
下面是旧实验的配置说明。

这是未标定的基础出图场景，不是 SC038HGS 厂商调校包。输入为 640×480
RAW10，固件必须启用 `CONFIG_MPP_SC038HGS_MONO`；输出为 YUV420，应用只读 Y。

三个文件由当前 SDK 的 `sc035hgs-640x480` XML/JSON 模板生成，保留其解析结构。
原文件 SHA-256 记录在 `source-sha256.json`。重新生成：

```sh
python3 tools/sc038hgs_raw/generate_isp.py --sdk /mnt/mydata/kRTOSSDK
```

AE、AWB 及全部自适应算法关闭。手动管线关闭 HDR、去马赛克、WB、CCM、
增益、Gamma、坏点、镜头阴影、降噪和锐化；CPROC 采用饱和度 0、对比度 1、
亮度和色调 0。手动白平衡系数保持 1、CCM 为单位矩阵但不启用。
黑电平扣除设为 0，避免套用其他传感器的黑电平；后续须实测暗场再调整。
XML 中未启用模块的模板表仍保留供解析，不能视作 SC038HGS 标定结果。

XML 的帧率元数据为 0（未知）。当前应用通过 `--exp LINES` 按行设置曝光，
默认 400 行，`--exp 0` 保留传感器初始化曝光，无需通过这些历史 ISP 配置控制曝光。
不能把外部 24 MHz 晶振当作内部像素时钟；这些配置尚未完成板端出图验证。

旧版本在 ELF 前部署这三个文件到 `/sdcard/app/isp/`，初始化时通过场景接口
加载并显式选择 XML/JSON，关闭后恢复原场景。当前 RAW 路径不使用这些配置。
独立探针的 `isp` 对照仍从该板端路径加载；需要此对照时手动复制本目录的
XML 和两个 JSON，正式应用的部署脚本不包含这些实验资源。
