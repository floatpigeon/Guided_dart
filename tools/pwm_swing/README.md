# PTK 7350 MG-D 四路 PWM 摆动测试

独立的 Dart V1 / RT-Smart 用户态诊断程序。使用硬件 PWM 产生 333 Hz 波形，
主循环每 10 ms 按单调时钟更新一次高电平脉宽。程序显式将下列引脚配置为 PWM，
启用输出和输入缓冲，保留原来的电压选择，并打印配置前后的寄存器读回。

| 测试通道 | PWM | 引脚 |
|---|---|---|
| CH1 | PWM1 | IO61 |
| CH2 | PWM2 | IO7 |
| CH3 | PWM3 | IO8 |
| CH4 | PWM5 | IO59 |

PWM0/1/2 共用一个周期，PWM3/4/5 共用另一个周期；初始化先关闭四路输出，
设定两组为 333 Hz，再设置四路中心脉宽并使能。每路高电平脉宽独立更新。
运行时须独占这两组 PWM，避免其它程序修改同组周期；同一时刻只运行一个测试实例。

参数依据 PTK 7350 MG-D 产品规格书：工作信号标为 `1520us/333Hz`，
允许脉宽 500/1500/2500 µs 对应 −90°/0°/+90°，供电 DC 4.8～8.4 V。
规格书中 1500 与 1520 µs 的中位标注不一致，测试暂以 1520 µs 为中心，
机械零位仍需单独标定。

## 流程

1. 四路保持 1520 µs，持续 2 秒；每 10 ms 读取一次芯片 PAD 输入电平，
   分别统计各引脚高/低电平次数，帮助判断信号是否到达芯片引脚。
2. 按 CH1 → CH2 → CH3 → CH4 依次摆动，每路做两次完整正弦往返；
   单次往返 4 秒，范围 1420～1620 µs，其余三路保持 1520 µs。
3. 四路同时做两次相同的正弦往返，共 8 秒。
4. 四路回到 1520 µs，保持 1 秒，然后逐路关闭输出并释放设备。

总时长约 43 秒。每个阶段打印通道、参数，每秒打印一次目标脉宽。
四路一起动作时，软件依次更新四路，未保证引脚边沿或更新时刻完全同步。

配置或输出调用失败、单调时钟/等待失败时，程序尝试关闭全部四路，返回非零。
SIGINT/SIGTERM 只在信号处理器中设置标记，由主流程关闭输出；中断时直接关闭，
不执行回中等待。SIGKILL、进程崩溃或系统故障无法执行清理，硬件 PWM 可能继续输出。

## 编译和部署

在仓库根目录执行：

```bash
bash .script/build-rtos pwm_swing
bash .script/deploy-rtos pwm_swing
```

产物是 `build-cross/pwm_swing/pwm_swing`，部署到 `/sdcard/app/pwm_swing`。
工具通过显式目标构建、部署。
构建/部署可沿用 `DART_BUILD_DIR` 自定义产物目录。

先空载连接舵机：橙色接对应 PWM 信号，红色接额定电源正极，棕色接电源负极，
舵机电源与板子共地。板端 msh 手动运行：

```text
msh> /sdcard/app/pwm_swing --help
msh> /sdcard/app/pwm_swing
```

正常结束会打印 `PWM test complete; all four outputs disabled`。
如需通过另一个终端停止，可向该进程发送 SIGTERM。

## launcher 开机测试

当前 `runtime/launcher/startup.list` 启用识别、录像和 IMU，PWM 测试行已注释。
需要开机测试时，先注释 `dart_app` 行，再启用 `/sdcard/app/pwm_swing &`。
普通 `&` 只启动一次并监督退出，不会重复摆动；每次重新上电或复位会运行一轮。

```bash
bash .script/build-rtos pwm_swing
bash .script/deploy-rtos pwm_swing
bash .script/deploy-rtos list
```

若旧 launcher 仍占用清单，可将经过回读校验的清单上传为
`/sdcard/app/startup_final.list.next`，支持暂存更新的 launcher 会在下次启动时启用它，
并将旧清单保存为 `.previous`。部署完成后重启板子，测试由 launcher 自动启动。
日志在 `/data/app/logs/pwm_swing.console.log`，确认出现正常结束行后，再核对实际动作
和连接器波形。运行后回读日志时，MTP 可能需要等待文件关闭。

恢复原业务时，注释清单中的 PWM 行、启用原来的 `dart_app` 行，重新部署清单并重启。

## 波形验收

用示波器或逻辑分析仪在四个连接器处逐路测量：

- 周期约 3003.003 µs（333 Hz），摆动过程中频率保持稳定。
- 中心高电平约 1520 µs，摆动范围 1420～1620 µs。
- 逐路摆动时，其余通道高电平保持约 1520 µs。
- 四路同时摆动时，检查舵机是否抖动、电源是否跌落、板子是否重启。
- 结束后四路均停止输出脉冲。

启动日志的频率/脉宽读回来自驱动缓存，只能检查配置路径，实际波形需要仪器确认。
PAD 高/低采样来自输入电平；观察到两种电平只能说明采样期间出现电平变化，
不能据此确认周期、脉宽或连接器后的线路正常。
主机的假 HAL / 虚拟时钟回归和交叉编译也不替代实板测量。
